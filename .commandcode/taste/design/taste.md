# Design taste

- Prefers a professional, minimal, restrained industrial/enterprise dashboard aesthetic (internal enterprise tool like a SCADA/monitoring console) over flashy or playful consumer-app styling. Confidence: 0.9
- Prefers muted dark navy/slate color palettes with a single accent color (teal or blue) used for active states and success indicators; red/amber reserved strictly for warnings and errors. Confidence: 0.9
- Prefers clean typography, clear data hierarchy, and restrained motion — no gradients-everywhere or bouncy animations; animation used only for meaningful state changes (e.g., staggered reveal of processing steps). Confidence: 0.85
